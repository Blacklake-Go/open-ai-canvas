# ONE 设计 Agent 会话

从 Studio 的设计 Agent 进入。ONE 登录状态控制会话列表、新建、改名和删除。当前会话保存在 Studio 地址的 `session` 参数中，浏览器刷新或返回时重新从服务端读取。会话中的上传素材使用 ONE 素材库。删除会话会移除会话与对话历史，上传素材仍可以在该帐号的素材库找到。

## 数据和接口

`090_design_agent_sessions.sql` 在 ONE PostgreSQL 中新增 `ai_studio.design_agent_sessions`。每条会话记录只对所有者开放。新建使用客户端 UUID `creationKey`，相同帐号和 key 的重试返回同一会话。历史更新使用 `revision`，后端以原子条件更新拒绝覆盖其他标签页写入的版本。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET、POST | `/api/v1/creative-agent/sessions` | 列出个人会话，或用 `name`、`creationKey` 新建 |
| PATCH、DELETE | `/api/v1/creative-agent/sessions/:id` | 改名、删除 |
| GET、PATCH | `/api/v1/creative-agent/sessions/:id/messages` | 读取或提交 `messages`、`revision` |
| GET | `/api/v1/creative-agent/sessions/:id/assets` | 读取该会话的可用素材 |
| GET | `/api/v1/creative-agent/sessions/:id/jobs` | 读取该会话的 ONE 生成记录 |

上传通过 `POST /api/assets/upload`，`studioId` 取 `design-agent:<会话 UUID>`。服务端在写入存储前验证会话所有权。会话动作使用 ONE Cookie，页面记录了预期的用户 ID 以识别标签页里的帐号切换。

## 文本对话与积分

用户选择 ONE 已发布的文本模型并点击发送后，页面通过生成报价和任务接口提交 `task_type=t2t`。URL 中的提示词只填入输入框。提交时后端锁定会话记录，校验帐号、模型和报价，并从该会话最近八条成功文本回复组装上下文。同一会话仍有排队或执行中的任务时，另一条提交和会话删除都返回 HTTP 409，重试原提交可以读回同一任务。

文本结果、状态和积分记录保存在 ONE 生成任务中。刷新页面通过会话的 `jobs` 接口恢复对话和状态。Worker 成功后结算预留积分，失败后按现有积分账本释放预留。

## 媒体技能

技能菜单根据 ONE 已发布模型的类型、模式、价格和可用路由显示生成图片、编辑图片、生成视频与图片转视频。每个技能单次生成一个素材，当前视频技能使用 5 秒。图片编辑与图片转视频要求当前会话中恰好一张可用图片，可以上传或引用画布中已有素材。

提交前展示服务端返回的模型与积分报价。取消保留输入，确认后才提交任务。后端在预留积分前重新校验投递模式、会话归属、参考素材及报价参数，参考素材使用 ONE 私有素材 ID。在 Worker 取得匹配类型的结果并完成归档后，任务与私有素材一同落库。成功结果可从对话打开，也会回到原会话画布。归档失败会报告失败并释放预留积分。

## 联调与回退

先在 ONE 隔离库执行原有迁移任务并核对 `pending=0`、`drifted=0`，再联调前后端。用两个独立帐号验证会话历史、素材和任务读取的归属；在两个标签页提交同一版历史时，第二次提交应收到 HTTP 409。

使用受控测试供应商验证媒体确认、归档、播放与失败解冻。使用本地磁盘存储的参考图通过签名 URL 提供给正在执行该任务的供应商。部署环境需要可从供应商访问的 HTTPS `PUBLIC_APP_URL`，以及服务端与 Worker 共用的存储签名密钥（使用现有 `STORAGE_SECRETS_ENCRYPTION_KEY` 及其配置回退）。签名有效期为 10 分钟，任务结束后立即失效。反向代理的访问日志须排除该签名 URL。

实际生成取决于环境中的模型配置、凭据和存储可达性。会话迁移本身不会搬移上游历史。回退时恢复上一个 ONE 前后端版本并保留新增表，以保存这次写入的会话。
