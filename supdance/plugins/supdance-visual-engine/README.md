# SupDance Visual Engine V2.0 独立插件

## 概述
SupDance Visual Engine 是面向 SupDance 平台的独立全站视觉、UI、阴影遮罩、交互动效与工作区恢复引擎插件。
遵循“非侵入式、独立模块、双入口单控制台、热插拔、上游兼容、统一配置、可预览、可回滚”的最高开发原则。

## 核心特性
1. **三层设计令牌体系**：Primitive → Semantic → Component 全站统一映射。
2. **多主题预设**：SupDance Native、Dark、Light、Studio 预设，支持自定义主题与对比度安全检查。
3. **UI 组件光学引擎**：按钮、输入框、下拉框、弹窗、抽屉、表格等全状态管理。
4. **E0–E4 深度阴影与遮罩系统**：独立配置模态遮罩、图片文字防穿透渐变、背景模糊与焦点还原。
5. **Motion 动效引擎**：物理弹簧动效、缓动曲线、页面路由过渡及 Reduced Motion 降级支持。
6. **图 1 工作区恢复动画模块**：多阶段环形运动轨道、浮动 UI 卡片与真实业务事件同步。
7. **独立 Visual Console 后台控制中心**：双入口单一控制台，集中管理 16 个功能模块，支持草稿实时预览与安全版本回滚。
