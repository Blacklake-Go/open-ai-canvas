# 站点多语言插件 (`supdance-i18n`)

当前版本 **1.3.0**：统一使用上游 i18next，支持八种语言；保留源码扫描、已有译文、翻译管理、草稿、审核发布、锁定与历史回滚。操作、预算配置、API 和部署回退说明见 [国际化扫描与翻译更新](../../../docs/content/docs/backend/supdance-i18n.mdx)。

本插件为 SupDance Canvas 提供热插拔站点多语言（i18n）能力，遵循 `yingce.plugin/v2` 插件契约与 SupDance 三层隔离架构。

## 核心能力

1. **八种界面语言**：
   - `zh-CN`（简体中文）
   - `en-US`（English / 英语）
   - `zh-TW`（繁體中文 / 繁体中文）
   - `ja-JP`（日本語 / 日文）
   - `ko-KR`（한국어 / 韩国语）
   - `es-ES`（Español / 西班牙语）
   - `fr-FR`（Français / 法语）
   - `de-DE`（Deutsch / 德语）
2. **后台插件管理与热插拔**：
   - 可在 `/admin/plugins` 统一开启或停用。
   - 插件开关不再改变宿主语言或隐藏宿主语言菜单，设备偏好由上游统一维护。
3. **后台语言管理与词条修改**：
   - 语言设置页（`/admin/i18n/settings`）：使用上游设备语言选择器。
   - 词条管理（`/admin/i18n/entries`）：管理原有扩展、上游界面、创作页及模型显示文案，支持八语言修改、自定义词条、完整 JSON 导入导出和审核发布。
   - 保存成功后以服务器 bundle 为准立即应用；失败保留草稿，删除覆盖恢复内置译文。
