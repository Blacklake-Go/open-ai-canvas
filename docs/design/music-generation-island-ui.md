# SupDance AI Music Generation Island UI & Audio Experience Specification (DOC-4)

本规范定义了 SupDance 专属 AI 音乐创作岛（Music Generation Studio Island，路由路径 `/toolbox/music`）的前端交互体系、组件分工、Web Audio API 波形播放引擎、歌词结构化编辑体验与多格式无损导出标准。

---

## 1. 创作岛整体布局规范 (Island Layout)

页面严格遵循 SupDance UI Design System 与桌面端/移动端全响应式标准：

```text
┌────────────────────────────────────────────────────────────────────────┐
│  Sticky TopBar: 标牌、模型状态概览、刷新历史作品按钮、当前语言切换器   │
├───────────────────────────────────┬────────────────────────────────────┤
│  Left Panel (7 cols / 桌面端):    │  Right Panel (5 cols / 桌面端):    │
│  - 模式切换 (简单模式 / 自定义)   │  - 创作历史列表 (Track Cards)      │
│  - 模型选择器 (4大模型)           │  - 真实阶段状态机徽章              │
│  - 歌词编辑器 (标签注入条)        │  - 64频段 Web Audio 波形播放器     │
│  - 伴奏开关 / 时长滑块 / 特有参数 │  - 单例播放守卫控制器              │
│  - 积分预占实时估算               │  - MP3 / WAV / FLAC 格式下载菜单   │
│  - 立即生成提交按钮               │                                    │
└───────────────────────────────────┴────────────────────────────────────┘
```

## 2. 双创作模式与动态参数适配

### 2.1 简单模式 (Simple Prompt Mode)
面向灵感速记与轻量创作者：
- 用户仅需输入风格与氛围描述（Prompt）。
- 伴奏开关由用户选定（开启时生成纯器乐，关闭时由模型智能自动填词演唱）。
- 隐藏复杂的段落标签和高级乐理参数。

### 2.2 专业自定义模式 (Custom Professional Mode)
面向专业影视配乐、音乐人与短剧主题曲定制：
- **歌曲标题 (Title)**：作品展示名。
- **结构化歌词编辑器**：支持多行歌词排版与段落结构引导。
- **模型动态参数槽**：
  - Mureka 9.5：人声性别与无损音质开关。
  - Suno v6：续写片段关联与风格标签输入。
  - Google Lyria 3.5：BPM 节拍速度 (40–240) 与调号 (Key) 下拉列表。
  - Eleven Music 2.5：分轨 (Stems) 提取选项。

## 3. 专业多行歌词编辑器 (Lyrics Editor)

### 3.1 结构化段落快速注入条 (Section Tag Bar)
在歌词输入框上方提供一键插入结构标记芯片按钮：
- `[Verse]` / `[Verse 1]` / `[Verse 2]`：主歌段落
- `[Chorus]`：副歌高潮段落
- `[Bridge]`：过渡段 / 桥段
- `[Intro]`：前奏引子
- `[Outro]`：尾声收束
- `[Instrumental]`：纯器乐间奏

用户点击芯片按钮后，编辑器光标处自动插入相应标记并添加换行，无需手动打括号。

### 3.2 字符限制与边界防护
- 实时计算字符数（当前字数 / 最大上限 3000 字）。
- 达到 90% 提示橙色警告；超出上限时输入框边框变红并禁用提交按钮。

## 4. 用户隔离的本地加密草稿存储 (User-Scoped Drafts)

采用带用户作用域（`user_id`）的 `localforage` 键值存储：
1. **防串号隔离**：存储键形如 `supdance:music:draft:${userId}`，彻底杜绝不同账号登录同一浏览器时的数据交叉污染。
2. **防抖自愈**：用户输入事件绑定 500ms 防抖自动落盘。
3. **页面初次加载恢复**：切换回音乐创作岛时自动读取上一次未提交的草稿内容。

## 5. Web Audio API 64频段波形播放器 (Waveform Player)

### 5.1 频段分析与波峰渲染 (64-Bar Waveform)
- 利用 Web Audio API 的 `AudioContext` 与 `AnalyserNode`。
- 音频加载完成后或播放期间，计算出 64 个具有平滑过渡（EMA 平滑滤波）的频段幅值。
- 通过 Canvas / CSS 柱状图直观呈现现代音频动态频谱。

### 5.2 全局单例播放守卫 (Single-Instance Playback Guard)
- **零自动播放 (Zero Autoplay)**：任何新生成完成的作品绝不自动发声播放，必须由用户显式点击播放按钮触发。
- **互斥播放控制**：全局音频控制器维护 `playingTaskId` 状态。当用户点击作品 B 的播放时，系统自动暂停当前正在播放的作品 A，绝不允许双音轨重叠杂音。
- **交互边界**：
  - 点击波形柱任意位置支持精准 Seek 寻道。
  - 播放控制按钮触控热区严格保证 $\ge 44 \times 44 \text{ px}$（遵循 WCAG 2.2 触控标准）。

## 6. 真实阶段状态机 (Realistic Progress Indicators)

系统彻底摒弃虚假的百分比计数器（如伪造的 `35% -> 42% -> 80%`），采用权威的五阶段离散状态机指示：

| 阶段代码 | 界面显示徽章 | 视觉指示效果 | 含义 |
| :--- | :--- | :--- | :--- |
| `submitted` | 已提交 | 蓝色圆点 | 任务已成功接收并在本地建单锁定积分 |
| `queued` | 排队中 | 橙色旋转指示 | 任务已进入上游计算集群等待资源分配 |
| `generating` | 正在生成 | 紫色呼吸渐变脉冲 | 音频神经网络正向扩散计算中 |
| `transcoding` | 转码封装中 | 青色动态微光 | 音频元数据注入、服务端 ffmpeg 多格式转码中 |
| `completed` | 生成完成 | 绿色成功对勾 | 音频渲染完毕，波形就绪，可供试听下载 |
| `failed` | 生成失败 | 红色警示图标 | 生成异常，同时展示错误原因并全额退款 |

## 7. 内存安全的多格式下载 (Multi-Format Downloads)

每个已完成的作品卡片右下角提供下载下拉菜单：
- **MP3** (标准压缩，文件小，兼容性最佳)
- **WAV** (无损未压缩，适合后期制作)
- **FLAC** (无损压缩高保真，极佳音质)

前端通过服务端签名 URL 或安全 Blob 流完成下载，并在下载完成后及时释放 `URL.revokeObjectURL`，杜绝浏览器内存泄漏。
