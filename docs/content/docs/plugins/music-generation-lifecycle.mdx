# 音乐插件生命周期

统一后台 `/admin/plugins/music-generation` 包含 Overview、Models、Pricing、Tasks、Test、Settings。渠道、凭据和价格由主站 `/admin/channels` 管理，不维护第二份密钥或价目。

音乐模块 1.3.0 要求宿主 1.7.4，RunningHub 协议包为 1.1.2。前端注册位于 `web/src/supdance/plugins/music-generation/index.ts`，清单位于 `supdance/plugins/supdance-music-generation/manifest.json`。配置启停在运行时生效；代码、宿主接缝和协议包需要匹配构建、部署及重启，不承诺零停机热插拔。

新任务检查平台、用户插件状态、渠道、模型能力、报价和余额。排空停止新接单，已有主站音乐任务继续查询、归档和结算；持久活动数量清零后保存停用状态。生命周期、平台准入和管理员审计同事务提交，失败不先改变内存。

停用/卸载保留作品、任务、资源、共享资产、配置备份、用户偏好、账单和流水。历史及私有授权下载继续可用。旧独立配置仅保留备份和历史读取，新任务走主站。旧后台测试通过原日志恢复原回执，不重新生成或补扣；保存失败只重试归档。

升级前备份匹配数据库、数据目录及设置密钥，核对旧独立任务并排空。回滚保留新增资源和账目，回切匹配程序和协议包，不删除账单或以旧数据库覆盖新增交易。详见 `docs/supdance/music-studio/`。
