# 音乐生成验证范围

音乐工作岛候选已接入主站渠道、报价、持久任务、资源、共享资产与账务。此页撤销旧文档中“47 项全覆盖”“5-Tier 全部通过”等缺乏对应执行证据的概括，不以源码声明代替验收。

本次在隔离环境恢复两条原后台测试回执，取得三首音频；新增纯音乐与自定义歌词两条真实 RunningHub 任务，共结算 27.8 积分，产生三首音频。隔离钱包不代表生产账务验收；生产没有部署本候选。

自动化验证覆盖报价/余额、并发幂等、分离轮询、原回执恢复、主站别名归档、部分输出权限、历史分页、生命周期及播放器。浏览器、真实生成、听感和设备检查分别记录，不能合并为“全模型通过”。

执行环境、任务号、文件元数据、账目、限制和逐项状态见仓库 `docs/supdance/music-studio/VERIFICATION.md`。实现与回滚见 `docs/supdance/music-studio/IMPLEMENTATION.md`。

人声角色、风格参考、Remix、人声与伴奏分离和局部重写须分别核对输入、按次报价、上游回执与结果归属。操作与现场版本核对流程见仓库 `docs/supdance/music-studio/ADVANCED_TOOLS.md`。

真实听感、人声及歌词遵循需要人工听音；其他模型、新扩展操作、真实手机软键盘和生产存储/账务不得从现有结果推定通过。
