# 上游 v1.8.5 与后续 main 源码集成

本次自有基线为已部署的 `feda18833728e8d646b51e9ddf79df2f002e2de3`；合并固定上游 `bae6a36c2e835733295a48087eb9c424ea619bc2`，共 19 项提交、287 个上游变更路径。最新稳定版本为 v1.8.5，另外包含发布后的创作历史、短剧版本恢复及 CI 更新。此记录在推送前生成，不以源码存在代表线上验收完成；实际生产证据另行保留。

## 保留边界

- 音乐插件及 RunningHub 协议包继续使用平台目录、任务、钱包、规范资产和下载；不新增收费测试，不修改售价和历史交易。
- 模型选择器保持后台启停、品牌归组及简介/价格配置；选中时同时关闭实际使用的紧凑或原生菜单，恢复触发按钮焦点。
- SupDance 翻译、支付、社交登录、HTML 页面、主题外观、内容筛查、ONE 身份及资产桥保留。已退役视觉引擎不恢复。
- 原有真实 Codex 本地连接动作与上游真实 MCP 连接列表并存；原先未实现的占位连接按钮由上游实际连接和市场替代，不假装它们已连接。
- 上游成片手动合成、版本预览及恢复与本站时间线精修并存。新增短剧界面接入原有六语言词库，业务标识、素材名、生成提示词不翻译。
- 生产生成副作用仍要求跨页面互斥，不吸收缺少 Web Locks 时仅依赖进程内锁的降级。没有跨页锁时明确拒绝，防止多页面重复物化资产。
- 仅运行中 Agent 操作状态使用的既有上游文字流光保留，含减弱动效处理；设计检测例外限定到对应样式文件，不关闭全局规则。

## 新上游文案清单

既有短剧翻译界面补齐 41 组原生六语言词条。新增 MCP 等上游界面及部分已存在的移动文案另有 460 个扫描项、412 个不同源文，按原始 Git 源码逐项核对来源并登记在 `supdance/i18n/upstream-v1.8.5-review.json`，状态仍为待翻译，未调用付费翻译、未发布空词条，也未视为六语完成。源码扫描基线更新只接受这份有来源证据的上游清单；运行时词库和未知翻译键校验保持。
