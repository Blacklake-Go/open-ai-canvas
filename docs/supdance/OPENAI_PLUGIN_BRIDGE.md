# Supdance OpenAI 插件业务桥接

桥接使用 `/api/supdance-openai/v1`。独立插件负责 OAuth、作用域、用户确认和插件执行记录。宿主接收经服务凭据认证的主体标识，检查主站账号和项目归属。服务令牌只通过 HTTPS 发送，访问日志不要记录认证头。

在宿主后端挂载受保护的 32 字节十六进制共享密钥文件，通过 `CANVAS_SUPDANCE_OPENAI_BRIDGE_SECRET_FILE` 指定容器内路径。受管 Compose 默认只透传变量，可在现有 `/data` 挂载中由容器服务账号独占读取文件，或通过部署覆盖只读挂载专用密钥。密钥为空或无效时路由关闭。移除变量并重建后端容器即可禁用。沿用已有数据模型和任务队列，无数据库迁移。

项目和画布读取遵循主站归属。分镜确认凭据绑定账号、项目、画布、版本、完整镜头内容和十分钟有效期。提交仅追加文本节点，重试复用原生画布变更回执。

审核文本需同时设置 `CANVAS_SUPDANCE_OPENAI_REVIEW_SUBJECT` 和 `CANVAS_SUPDANCE_OPENAI_REVIEW_MODEL`，分别为专用审核账号的用户 ID 和系统文本模型记录 ID。插件请求必须声明 `maxCredits: 1000000`（1 积分，单位微积分），主站才接受。单次请求最多 2048 输出 Token，预授权上限为 1 积分，每分钟最多四次请求。费用从该账号的现有余额由主站原有账本结算，模型报价缺失时拒绝入队。公开用户的文本生成等待单独配置权益。

当前桥接包含项目与画布读取、分镜确认写入和审核文本。项目创建与素材生成需要完成各自的报价、幂等和权限验收。正式提审前要验证真实账号 OAuth、受众和撤销、真实任务账单、跨账号拒绝、画布版本冲突及审核录屏。
