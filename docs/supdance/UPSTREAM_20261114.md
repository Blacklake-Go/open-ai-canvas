# 上游 main 与 SupDance 完整更新

源码起点为自有 `0c0af6568cd2578402940ad55ae566df0f43a55e`，合并上游 `3979305c1413be231cbaef242e50afc67f553c5e`，包含前次基线之后的十二项提交。上游正式版仍为 v1.8.5，本次同时纳入随后 main 的修复，不将开发分支称为新正式版。

## 冲突取舍与保留

- 原工作区未提交内容保留；其中法律页、HTML 后台与登录页已有相同或更新实现进入自有 main，以线上八语言版为基线，避免退回六语言版。App Store 和 TapTV 演示源码按用户确认不开放生产路由。
- 保留音乐、RunningHub、Waffo、社交登录、HTML 页面、紧凑模型选择器、外观设置、灵感合规锁、ONE 身份与钱包桥、Codex 和时间线精修。退役视觉引擎不恢复。
- 上游模型菜单移除通用渠道标签，保留个人渠道提示的翻译及本站紧凑选择器。上游分镜编辑、项目素材关联、预演入口和审批完整预览吸收，UI 文案接入原词库。
- 登录采用上游跨标签账号隔离与失败阻塞，同时保留本站加载占位、社交登录和无播放徽章的背景视频。两套 OAuth 绑定方法名称冲突通过区分社交插件接口处理，不静默覆盖既有绑定行为。
- 不改写用户名称、提示词、模型标识、生成参数或历史账务。
- 新增文案由原生、创作与静态界面词库共同覆盖。源码扫描中诊断日志、测试素材标签和 Agent 提示词维持规范原文；静态编译器与源码扫描器的占位符命名差异另以实际编译目录核对，逐条证据见 `supdance/i18n/upstream-20261114-review.json`，不以改基线掩盖未翻译界面。
- 约 1.7 万条后端生成词库共享的条目构造函数禁止内联，避免每个调用点重复展开翻译 map 而放大 SSA 编译内存。每次仍构造新的条目和 map，顺序、内容、覆盖规则与接口保持不变；生成器保留该非生成头部。
- 缩略图缓存测试改用上游认证完成后的 `setActiveUserScope` 切换，保留跨账号重新解码断言；直接改写存储提示不再被当作已认证切换。多步骤真实模型编辑器测试为完整应用／撤销流程留出执行时间，不删减价格、能力与协议断言。

## 数据库与部署

已发布 Schema 1–102 的版本、名称和校验和保持。上游 102 `wechat_oauth`、103 `mcp_tenant_boundaries`、104 `agent_storage_limits` 映射为本站 103、104、105，保留各自校验和及迁移实现。

MCP 安全迁移会撤销旧连接授权但保留凭据和回执。部署前只读确认当前 MCP 连接为零。Agent 新增并发、历史容量和进程资源边界；不删除既有历史。微信登录需另行配置有效网站应用，不自动启用。

沿用实际 PostgreSQL、Redis、独立 Agent 和持久 Web 编排，保持宿主挂载与私有配置。先备份数据库、数据目录与设置密钥，在恢复副本验证两轮迁移和保护表一致，再排空任务切换。升级后不得覆盖旧数据库丢弃新增交易；故障优先前向修复。
