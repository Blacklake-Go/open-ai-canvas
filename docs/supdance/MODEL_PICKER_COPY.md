# 模型选择器宽度与说明

简洁模型选择器 1.1.0 将桌面菜单由 560px 收到 480px，保留 144px 品牌栏，右侧列表由 392px 收到 312px。右侧说明可换行，桌面说明独占一行，避免价格挤压文字；手机沿用上下排列与 44px 点击区域。

`supdance/config/model-descriptions.json` 保存本次审校的 92 个模型条目说明，包括当前未启用条目。说明描述创作用途，不保证生成速度、质量排名、角色一致性或必然成功，也不把供应商原生能力视为本站已经开放的参数。

核对依据：线上 `/api/model-catalog` 的渠道、协议与能力配置，以及以下官方资料：

- [Google 图片生成与编辑](https://aistudio.google.com/docs/image-generation)：核对 Nano Banana 系列定位；本站没有开放的联网搜索等能力不写入说明。
- [RunningHub 标准模型目录](https://www.runninghub.ai/call-api/search-api/standard-model)：用于确认当前接入系列与操作类型。部分渠道版本别名没有独立官方介绍，说明仅依据本站实际输入类型与创作用途，不声称已核验所有原厂版本差异。
- [MiniMax Audio & Music](https://www.minimax.io/audio)：核对语音与音乐的用途区分。

Nano Banana Pro Ultra 的当前能力配置仅提供 1K、2K、4K，展示名称应删除 8K 字样。模型键、供应商键、协议、能力参数、价格、启停状态均不随文案更新改变。

线上有尚未合入本分支的页面更新时，可以从当前完整静态发布目录复制新发布，仅追加本插件的版本化 CSS 入口，保留已有 JavaScript 和页面。此方式是现有部署的定向静态发布，源代码仍在插件目录维护；下次完整构建自然包含同一规则。不要以旧分支的整站构建覆盖更新的线上页面。

发布时先保存数据库和旧静态入口。文案通过事务更新，逐行检查原值，任一条目不匹配则全部回滚。更新后比较非展示字段和价格表，确认无变化，并核对公开目录中的说明。回退使用保存的文案原值及旧静态入口；无数据库结构迁移。

验收应覆盖真实创作页的明暗主题、桌面与手机、长名称与价格范围、模型选择、Escape 关闭和焦点恢复。付费生成不属于本次文案及布局验收。
