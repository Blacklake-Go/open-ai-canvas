# HTML 页面管理后台

入口 `/admin/plugins/html-pages` 包含 HTML 工作台、站点页面与页脚设置。界面消费宿主 `--admin-*` 令牌，复用后台弹窗和开关，跟随后台明暗主题。插件局部样式不覆盖站点或画布；页脚预览保留前台页脚自己的作用域。

## 保存与发布

- 新建页面默认为草稿。列表、标题、路径、公开状态和 HTML 统一通过「保存页面」持久化；删除也在保存后生效。
- 页脚与站点页面的页脚显示策略独立保存。保存 HTML 不丢弃未保存的页脚编辑，保存页脚不替换 HTML 草稿。
- `/p/:slug` 与公开接口只读取已保存且已发布的页面。公开链接不是未保存草稿的共享预览。
- 路径归一化后不可重复，须以英文字母或数字开头，后续只允许字母、数字、连字符和下划线。ID 必须非空且唯一，标题和 HTML 不可为空。非法批次返回 HTTP 400，整体不写入。
- 重置 HTML 立即恢复默认集合，并删除所有自建页面，包括已保存内容。重置页脚不重置 HTML。
- 初始读取失败时禁止保存，并提供重试。离开未保存页面时提供确认提示。

## 预览边界

编辑器 iframe 只开放 `allow-scripts`，不授予同源权限。预览脚本无法读取宿主 DOM、Cookie 或持久存储；模板主题按钮使用当前 iframe 内的临时存储，重新加载后清空。主题与存储引导只注入预览副本，不进入保存、复制或下载内容。

格式化使用现有 Prettier HTML 解析器及严格空白敏感策略。解析失败保留原文，异步完成时也不覆盖后续输入。

## 验证与回退

专项测试覆盖预览文档、六语种词条完整性、路径校验、权限、草稿和发布读取、独立保存及重置。Chrome 验收使用本地调试数据目录；生产认证、既有配置及真实触屏输入须在对应部署验收。

无需数据库迁移，SystemSetting JSON 结构不变。回退可恢复插件前端和保存校验代码，已有页面与页脚数据继续可读。
