# 上游 v1.8.7.1 源码集成

以自有主线 `0819fcee1b33c4970c110e1081997eca1eef863a` 为基线，合入上游正式标签 `v1.8.7.1` 和同一提交的上游 main `882a1d1a50523fe992831e2b0da69f44b4469835`。本地集成版本为 `v1.8.7.1-supdance.1`。

## 二开保留

- `supdance/plugins/` 目录的七份插件清单和源码保持原样。音乐及 Mureka 素材归档、页面管理、邮件、社交登录、八语言、Waffo、工作流助手以及 Codex 入口沿用原插件身份。
- 通用模型测试继续将支持的音乐模型引导到带报价和结算的专用测试入口。音乐异步回查保留可重试错误处理和历史渠道别名，其他模型沿用上游入队时锁定的协议发行版。
- 团队账务保留上游的付款账户与封顶前用量，同时保留 SupDance 一小时缓存写入用量。创作页保留个人空间的音乐入口，团队空间沿用上游模式限制。
- 保留画布工作台的语言入口、Codex、时间线、小组空间路由及灵感展示资格和本地化。上游新增团队及模型设置文案仍需八语审校。

## 数据库

本站 Schema 1–108 的编号、名称和校验和沿用原版本。上游 106–109 分别映射为 109 团队空间及积分账户、110 公司与小组、111 共享工作区内容、112 模型协议版本。官方素材独立账本保持 4。

上线前需用备份恢复副本验证 `migrate-schema up` 和 `migrate-schema verify`，同时核对个人积分余额、冻结金额、个人历史订单、素材引用及已安装协议包。插件归档与 `.settings-key` 应随数据目录备份。账本升级后，旧 108 程序不能直接连接 112，回退需结合同一时间点的数据库与数据目录。团队开关缺省关闭。本次仅集成本地源码。
