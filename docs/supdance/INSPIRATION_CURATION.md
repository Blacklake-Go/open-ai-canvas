# 灵感中心策展

管理入口为「页面管理 → 灵感中心」，路径 `/admin/plugins/page-management?page=inspirations`。既有公开开关、首页开关、审核锁和个案审核继续由「模型展示 → 灵感大厅管理」维护。

1. 在案例库搜索标题或提示词，勾选跨页案例，批量添加或移除风格、设置或清空提示词类型。原来源分类及标签继续保留。预置风格可直接使用，额外风格可以在「分类与标签」中创建。
2. 将有封面、当前符合公开条件的案例加入精选，最多 12 条。拖动或上下移动调整同组顺序；置顶项优先。可修改精选标题和封面横纵焦点，并切换桌面和手机预览。展示标题仅针对精选，案例详情继续使用原内容。
3. 要控制完整的前台目录，在「案例库」按来源、风格或提示词类型筛选，可按标题或日期预排序。批量加入已选择的条目，或将整个筛选结果按当前排序加入「公开清单」。可移除条目、拖动、上下移动，或输入全局名次跨页调整。
4. 保存草稿后单独发布。自动目录沿用现有推荐规则，符合审核的新收录会进入前台。发布手动清单后，前台公共案例仅从清单选取，默认按清单名次显示，标题和日期排序也在已发布范围内工作。清单不包含的案例仍保留在后台，可以稍后加入。首页精选单独维护，发布后只有同时满足目录和审核条件的案例可以展示。
5. 「发布记录」可恢复最近 25 次中的历史版本。恢复动作生成新发布记录，保留当前草稿和原历史版本。已失去公开资格的案例会被即时过滤，历史快照无法重新授权。

策展状态位于已有 `system_settings` 的 `supdance.inspiration.curation`，不可变快照使用 `supdance.inspiration.version.<id>`。修改通过事务、版本号检查和管理员审计提交。无需数据库迁移。发布或回滚不会改写上游提示词、原始封面和署名，也不改变普通用户的自建收藏、导入内容或生成权限。

内置 22 条案例与原有来源目录都在服务端核对公开开关和逐条审核后提供。旧首页组件同样读取受控精选池。构建的客户端代码不包含内置案例正文。

后台 API 为 `GET /api/admin/inspiration-curation`、`GET /api/admin/inspiration-curation/catalog?q=...` 和 `POST /api/admin/inspiration-curation/{draft,publish,rollback}`。写请求都需 `expectedRevision`，保存草稿还需 `document`，回滚需 `version`。旧版本并发写返回 409。匿名 `GET /api/public/inspirations/curation` 只返回通过实时公开策略的已发布内容，并使用 `Cache-Control: no-store`。

`document.galleryOrder` 记录手动清单的案例 ID 和顺序，未提供时沿用自动目录，空数组发布为空目录。服务端将同一发布版本应用到来源包、上新、翻译和受保护缩略图。管理员仍能检索未加入清单的已收录案例。
