# 网站维护集成候选

本次仅处理 SupDance 网站的开发、维护、部署和上线测试。原主工作区保留，集成在独立分支进行。候选基于 `main@b2c8b2e8` 的上游原生多语言版本，合入音乐 1.3.0／RunningHub 1.1.2、电商和小说改编六语、游客入口及文本缓存与上下文计费。

## 行为与边界

- 原生中英法德日韩是宿主语言来源。电商与小说改编使用独立 i18next namespace，每种语言 2,308 条；用户文字、模型 ID、业务参数和服务状态不被翻译。独立价目表复用同一语言偏好，完整静态文案匹配替代子串替换，模型标识和金额单元格保持原值。
- 游客登录、注册共用药丸入口；首页和 welcome 提供访客可用的条款、隐私、AUP 与支持入口。工作区页脚可换行，链接保留 44px 触控高度。原 Mureka 图标和视频输入过滤一并保留，过滤不会修改后台模型启用状态。
- 音乐只复用主站渠道、报价、任务、账务和后端稳定资产写入。刷新或恢复不重复注册素材；既有收费生成不重复执行。
- Schema 83 新增订单与成本上下文分档，以及一小时缓存写入子集。订单冻结全部费率，供应商总输入选择整次请求的档位，输入和输出同时换档。原生 Anthropic 与 OpenAI 兼容的顶层／嵌套缓存写入均归一化，不重复计入输入。
- 商业策略保持上游价加 25%，保留既有赠金与返佣；实际价档更新须在代码发布后，以备份、版本检查和管理员服务验证完成，不在迁移中改写余额或历史账单。

## 已取得的阶段证据

生产 Schema 81 备份副本完成 81→82→83，141 张原有业务表的原列指纹一致。PostgreSQL Schema 与音乐恢复专项、缓存分档及成本专项、真实创建控件语言切换测试已通过。独立价目表对真实 HTML 的六语、金额／模型保护和中文回切测试通过。

第二轮完整推送门禁为 12 项、0 失败。其后补入原工作区模型图标／视频输入过滤和顶层缓存用量修正，必须对最终提交再跑完整门禁。支付包双架构与 Agent 静态检查由 CI 覆盖；缺少 Redis 时相应用例不能声明本地已执行。

真实页面已验游客入口及390px注册浮窗；页脚横排后的高度为52px。自动浏览器策略阻止后续语言切换，因此其他主题、账户、电商完整链路及上线运行验收仍待完成，不能以 DOM 专项或健康检查替代。

## 发布与回退

使用固定版本 Release 镜像、同版 Host Updater 和受管 Compose。现有生产存在覆盖镜像内容的宿主二进制、插件包和静态目录挂载，升级前必须逐项核实实际服务源，保留原 Compose、环境和数据备份；仅拉取新镜像不能证明新代码生效。

先备份并验证迁移，再运行新后端；禁止在生产备份副本上启动任务 worker。新增列不应手工删除。回退二进制需要匹配 Schema 的数据库备份，并核对备份后已发生的任务、资源与账务；保留旧资源和收费记录。线上版本、实际挂载、语言／登录／素材／账务路径及两条维护分支都通过后，才能将发布标记为完成。

Waffo 网站提示词筛查仍是单独未完成项：代码接入、商户配置与调用验收缺少完成证据；外部商户申请与重新提交不属于本轮网站操作。
