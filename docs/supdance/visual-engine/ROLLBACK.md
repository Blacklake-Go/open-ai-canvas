# 回滚与恢复
## 配置回滚
进入 Visual Console → 版本发布，比较历史快照后点击回滚。服务端校验 rollback 权限与预期 revision，将所选内容保存成新的发布版本；历史记录与审计保留。并发冲突返回 409；失败保持当前稳定配置，草稿不会冒充发布成功。

## 生命周期恢复
停用立即恢复宿主原生样式，移除侧栏入口；在插件管理重新启用。卸载保留配置时可重新安装恢复；清理配置是显式选择，主题、草稿、快照和迁移备份会清除，权限与审计保留。对真实宿主用户、项目、素材和任务没有删除操作。

## 代码回滚
源码升级前保留上一 release、二进制、web-dist、镜像与环境指针备份。发生候选失败时恢复上一镜像和挂载指针，按原 Compose 仅重建对应服务，核对 readiness、build commit、静态入口和摘要。需要同时恢复迁移前配置时，先备份当前插件数据，再按对应备份恢复本插件命名空间。不要回滚宿主业务数据库来撤销视觉配置。

运行失败默认恢复 Native；任何回滚都要检查旧标签页的带 hash 资源仍存在、焦点遮罩已清理、登录及后台仍可访问。
