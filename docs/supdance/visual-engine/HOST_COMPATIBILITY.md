# 宿主兼容性
插件版本 2.0.1，配置 Schema 2，清单最低宿主版本为 1.7.3。运行时以宿主扩展能力决定能否挂载，构建版本用于诊断。缺少必需能力时，根令牌、画布、浮层、AntD 和启动加载器统一回退到宿主。既有发布包、草稿及回滚记录继续使用。

必需接口包括主题、画布、浮层扩展与脱敏启动诊断订阅。浏览器必须支持 CSS Custom Properties 和减少动效查询。Popover 由宿主 AntD 负责定位。后台路由和正式启用的非 Classic 皮肤保有主题优先权。动效总开关沿用全站行为，路由与原生加载组件沿用宿主实现。

## 视觉引擎迭代验收

- 只读核对生产 `www.supdance.com`，实际前端版本为 `v1.8.0-supdance.2`，公开配置修订 `2693e2d34e8fc6fc` 已启用 `studio`，访客页面仍显示宿主主色。独立入口 `one.supdance.com` 的视觉发布接口返回 404。
- 用 `CANVAS_BUILD_VERSION=v1.8.2 bun run build` 在现有 SupDance 宿主上复现版本升级条件。候选构建在 Chrome 桌面浅色及手机深色中加载同一份公开发布包，分别应用 `#e11d74` 和 `#f43f5e`。本地拦截发布包响应模拟换版与启停，已打开的登录弹窗遮罩随更新切换到 13px 模糊和 65% 不透明度，停用恢复宿主 5px 和 48%，并验证 Escape、`/create` 导航及历史回退。此验收使用公开数据及本地模拟生命周期响应。
- 升级门禁检查应用挂载、Router、皮肤回调、弹窗和抽屉扩展是否保留，并用运行测试核对停用清理、后台及非 Classic 皮肤优先权。对 `upstream/main@cd2512eb` 的合并试算仍有计费、账号和数据库迁移等冲突，完整上游集成需在独立候选中解决并验证。

## 1.8.0 历史验收与 UI 差异

- 用候选前端 `v1.8.0-supdance.3` 和线上公开的同一份 `studio` 发布包运行 Playwright。工作台和新建自由画布的明暗主题应用了各自的主色。登录弹窗在两种主题下均应用 8px 模糊、65% 遮罩与 14px 圆角，并可用 Escape 关闭。
- 通过 `bun run build` 和 Vite Preview 复核生产构建。以线上公开修订 `2693e2d34e8fc6fc` 验证 1440×900 下的画布明暗切换，以及 390×844 下的访客首页主题、登录弹窗样式和 Escape 关闭。
- 本地后端沿用旧版隔离产物供登录和新建画布，Agent 会话与画布实时接口返回 404。运行态验收覆盖主题和浮层，生产环境待发布后复核。
- 对照 1.8.0 合并提交 `bc7c1ace` 与其 SupDance 父提交，创作首页将独立模式标签和输入区合并进 `CreationModeCard`，首页输入区省去原先的渐变边框包装。侧栏品牌区改用新字形容器，展开时只显示站点名，旧版工作台副标题移除。资产页的方舟肖像抽屉被认证弹窗和设置里的管理入口替换。这些是宿主组件改动，主题适配后仍会保留。

升级时检查 compatibility.ts 与 baseline.json 的源文件/耦合点、运行模块测试、生产构建及 Router/主题回归，最后在候选环境验收。当前静态注册清单清除了实际不存在的历史 legal 文件条目，未替换法律页面业务。未来版本须再次验证，不能宣称自动永久兼容。
