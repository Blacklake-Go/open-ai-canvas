# 宿主兼容性
插件版本 2.0.1，配置 Schema 2。最小版本声明为 1.7.3。运行检查接受 1.7.3、1.7.4 和 1.8.0 系列，并要求宿主扩展存在。其他版本或缺少必需能力时使用宿主样式。1.8.0 适配只改前端版本检查，沿用服务端已发布的预设、主题、动效开关与页面规则。

必需接口包括主题、画布、浮层扩展与脱敏启动诊断订阅。浏览器必须支持 CSS Custom Properties 和减少动效查询。缺少 WAAPI 时页面过渡即时切换，CSS Layer 缺失时使用根标记作用域，Popover 由宿主 AntD 负责定位。

## 1.8.0 验收与 UI 差异

- 用候选前端 `v1.8.0-supdance.3` 和线上公开的同一份 `studio` 发布包运行 Playwright。工作台和新建自由画布的明暗主题应用了各自的主色。登录弹窗在两种主题下均应用 8px 模糊、65% 遮罩与 14px 圆角，并可用 Escape 关闭。
- 通过 `bun run build` 和 Vite Preview 复核生产构建。以线上公开修订 `2693e2d34e8fc6fc` 验证 1440×900 下的画布明暗切换，以及 390×844 下的访客首页主题、登录弹窗样式和 Escape 关闭。
- 本地后端沿用旧版隔离产物供登录和新建画布，Agent 会话与画布实时接口返回 404。运行态验收覆盖主题和浮层，生产环境待发布后复核。
- 对照 1.8.0 合并提交 `bc7c1ace` 与其 SupDance 父提交，创作首页将独立模式标签和输入区合并进 `CreationModeCard`，首页输入区省去原先的渐变边框包装。侧栏品牌区改用新字形容器，展开时只显示站点名，旧版工作台副标题移除。资产页的方舟肖像抽屉被认证弹窗和设置里的管理入口替换。这些是宿主组件改动，主题适配后仍会保留。

升级时检查 compatibility.ts 与 baseline.json 的源文件/耦合点、运行模块测试、生产构建及 Router/主题回归，最后在候选环境验收。当前静态注册清单清除了实际不存在的历史 legal 文件条目，未替换法律页面业务。未来版本须再次验证，不能宣称自动永久兼容。
