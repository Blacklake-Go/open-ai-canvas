# 视觉 Token
Primitive → Semantic → Component：基础尺寸和排版配置生成语义 CSS 变量，再映射宿主与 AntD 组件 Token。4 款独立预设为 Native、Dark、Light、Studio；Native 直接恢复当前宿主基线，深浅色独立定义。自定义主题以 custom- 前缀标识，可复制、重命名、保存当前调色、删除、JSON 导入导出。

排版包含 label 11/16、caption 12/18、ui 13/20、body 14/22、heading 16/24、title 22/30、display 32/40；可调整字号、行高、字重、字体白名单与基础间距。系统中文字体、Inter、JetBrains Mono 都使用宿主资源，不加载外部字体脚本。

组件常规/紧凑/微型高度默认 36/32/28px；移动控制台最小触摸目标 44px。按钮、输入、卡片、菜单、浮层、标签具有独立圆角。Checkbox/Radio、Switch 和主命令保持独立色彩角色。焦点宽度/偏移、按压缩放、悬停位移和禁用透明度可编辑。

宿主强制非 classic 皮肤优先，控制台显示只读原因；管理后台保留宿主视觉。发布配置优先于允许的用户模式，system 跟随宿主/系统偏好。任何清理都还原插件原先接管的值和 priority。诊断报告真实对比度，不把旧的用户配置自动改成新默认色。

8 个内置预设/模式组合通过当前对比度检查；用户自定义颜色需要在诊断页复核。正文目标 4.5:1，必要控件状态目标 3:1。
