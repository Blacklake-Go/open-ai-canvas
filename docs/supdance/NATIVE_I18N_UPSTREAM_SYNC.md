# 上游 v1.7.3.7 与原生多语言集成

本文保留 v1.7.3.7 集成时的历史证据。当前国际化合同已由[八语言国际化统一说明](I18N_UNIFICATION.md)取代：繁体中文和西班牙语已加入原生语言列表，法德专属目录已补齐，后台通过明确注册的键发布上游资源覆盖。下文的六语言范围、法德缺译回退和核心文件无差异均只描述当时状态。

## 源码与语言合同

从自有远端 `main@83b6cacb` 完整合并正式标签 `v1.7.3.7`（`878b515b`），自有版本 `v1.7.4-supdance.8`，要求 Schema 82。包括共用登录面板、页面预取、电商五步流程、插件修复、反馈资源引用和缓存写入计价。主工作区未提交工作保持原状，使用隔离分支集成。

界面直接使用上游 `web/src/i18n`、`useLocaleStore`、`LanguageMenu`、`LanguageOptionGrid` 和 `switchLocale`。支持中英法德日韩六语言，首次按浏览器语言选择，偏好保存在设备 `yingce:locale`，用户切换后整页刷新。Ant Design、dayjs 与 HTML lang 同步。旧插件停用、缓存或后台词条更新不能重置原生语言。

旧全页 DOM 观察翻译与 i18next postprocessor 覆盖退出。SupDance 专属显式 key 使用同一 i18next 实例的 `supdance` namespace，保留词条数据和审核发布接口。旧后台语言策略页改为原生设备语言选项，不再显示失效的全局启停、排序与 DOM 翻译开关。繁中和西语旧词条数据保留，但不加入原生语言菜单。法德缺少的专属译文回退中文，法务正文回退英文权威文本；不代表全站六语完整翻译。

## 冲突与业务边界

采用上游共用登录/注册/找回密码面板及弹窗/页面模式，SupDance 社交登录移到共用表单，注册仍要求协议同意。保留音乐准入、统一音频任务、定价与法务导航、Codex、视觉引擎和品牌配置。插件管理同时保留上游详情弹窗和自有控制台入口。没有改写既有迁移的名称与校验和。

## 升级与回退

Schema 82 新增缓存写入价格与用量列，默认 0。Anthropic usage 归一修正会改变先前少计输入的账单，因此不可当作纯 UI 更新上线。生产升级前需要备份及隔离恢复副本的当前版本 → 82、幂等与数据核对；Web/Backend 同版本更新。独立 yingce-agent 保持现有部署，本次其源码相对上游标签无差异。

本次只集成源码，不代表生产数据库迁移、重启或发布完成。数据库升级后回退需要匹配旧程序和升级前数据库备份，不能只切换前端。

## 验证记录

扫描新增/变化的 182 条待译源文全部通过 AST 扫描与正式标签源码逐条匹配，无新增自造界面文案。按本轮直接使用上游的要求刷新源码扫描基线，继续保留未译回退；后续未知 key、源文变化和译文失效门禁不放宽。审查明细保存在隔离工作区 `.local/cache/i18n/upstream-source-review.json`。

专项运行回归覆盖六种原生语言、旧插件停用/发布不改变原生 locale、不覆盖上游词条，以及扩展 namespace 插值。独立运行验证了首次浏览器语言识别、保存与恢复偏好、同语言不重复刷新。上游核心 `i18n/index.ts`、`use-locale-store.ts` 和 `language-menu.tsx` 相对正式标签无差异。
