全量回归发现旧定制中的空用户路径会进入内部全渠道上下文，现已恢复上游的登录目录校验；访客只读目录继续显式使用默认分组，并校验渠道可见性。能力查询也在解析请求前检查登录，逻辑模型接口遵守相同边界。ONE 桥的逐条消费/退款记录仍沿用原接口排除预留行的规则，回归用例使用真实流水类型，不改变账务数据或筛选语义。

停滞下载回归的清理断言接受“暂存目录尚未创建”，仍拒绝任何残留文件和其他目录读取错误。网络停滞可能在创建暂存文件前被取消，目录不存在本身不代表清理失败；停滞分类、可重试性和时限断言保持原样。

依赖审计发现上游直接固定的 `undici 7.28.0` 存在已发布公告，故仅把 Pi Agent 的该依赖及锁文件固定到 `7.30.2`，保持 Agent SDK 版本不变。依据为 [Undici 官方安全修复](https://github.com/nodejs/undici/releases/tag/v7.30.2)，运行时测试及升级后审计一并验证；不执行整库自动依赖升级。
