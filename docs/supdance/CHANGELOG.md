# SupDance Canvas — 定制维护变更日志 (CHANGELOG.md)

## 首次创作引导

新用户可选择分镜示例并编辑。游客提交纯文本后，登录回到创作页时恢复当前标签页的草稿，仍需用户手动发起创作。

## 创作结果卡恢复原版

移除后来添加的模型标识与规格标签、固定提示词建议和重复操作。沿用原有的生成同款、预览、添加到画布与下载入口。

## Seedream 5.0 Pro 文生图画幅

RunningHub Standard Model 1.1.7 将该端点的画幅与分辨率档位一起转换为像素宽高，避免上游的 `resolution` 字段覆盖显式尺寸。1:1 的 1K 请求发送 1024 × 1024，2K 请求发送 2048 × 2048。

## 恢复统一创作流程

图片生成回到创作对话，图片和视频结果在同一会话中展示。旧图片会话地址自动进入原有创作页。

## 定价表社交媒体页脚

定价表和法务页面共用 HTML 页面后台的社媒链接配置和品牌图标。后台新增 Threads、Discord、Reddit 编辑字段，保留已有社媒项及其顺序。
