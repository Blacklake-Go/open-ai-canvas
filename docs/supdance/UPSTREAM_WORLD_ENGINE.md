# 世界引擎集成

SupDance 从已发布的 `832831ad` 起合入上游 `5ca284ce`。同时并入生产已使用的 OpenAI 桥接 `22809961` 与充值界面 `3e2c1f79`，使镜像与前端发行文件可以在同一提交构建。

## 使用入口

登录后从自由画布添加「世界引擎」节点。场景可调整天气、时间、地面与远景，也可加入布景、演员和道具。动画工作区提供相机运镜、路径和时间轴。镜头画面可下载为截图，并把构图、白模或深度素材保存回画布。

## 数据和发布边界

沿用原画布场景文档与资源保存接口。世界环境、路径和运镜作为场景数据保存，可读取没有这些字段的旧场景。数据库与独立官方素材的迁移文件沿用 112 和 4。生产回退需同时核对应用镜像、SPA 当前入口及已保留的散列资源。存量用户写入应保留，降级工作台前须考虑旧界面保存新场景时的字段兼容性。
