# 03 — 网站前台与认证系统视觉规范 (Public & Auth UI Specification)

> **设计层级**：Layer 3 — Application Design System (Public Scope)  
> **适用路由**：`/login`、`/register`、`/forgot-password`、`/zh/login`、`/welcome`、`/share/canvas/:token`。  
> **定位目标**：打造品牌感极强、转化率高、跨端响应丝滑且完全由后台外观设置驱动的公开门户与认证体系。

---

## 1. 认证场景架构 (`AuthScene`)

认证页面统一由 `web/src/pages/auth/auth-scene.tsx` 承载，采用经典的「左侧品牌影像区 + 右侧表单操作区」双分栏布局：

```text
┌────────────────────────────────────────────────────────┐
│                      AuthScene                         │
│  ┌───────────────────────────┬──────────────────────┐  │
│  │ 左侧品牌影像舞台           │ 右侧表单操作卡片     │  │
│  │ (Brand Stage)             │ (Form Container)     │  │
│  │                           │                      │  │
│  │ · 品牌名称与大标题         │ · 顶部多语言切换     │  │
│  │ · 动态品牌视频 / 海报     │ · 登录 / 注册 / 找回 │  │
│  │ · 副标题说明文案           │ · 第三方登录 (OAuth) │  │
│  │ · 页尾备案号与版权         │ · 协议勾选与提交按钮 │  │
│  └───────────────────────────┴──────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

### 1.1 左侧品牌影像舞台规范
1. **背景视频与海报**：
   - 视频源由后台 `authVideoUrl` 驱动，视频封面由 `authVideoPosterUrl` 驱动。
   - 视频默认 `muted loop playsInline autoPlay`。
   - **减弱动效偏好响应**：当检测到用户开启系统的 `prefers-reduced-motion` 时，必须自动暂停视频播放，降级为展示静态海报封面。
2. **文本信息排印**：
   - 品牌大标题 (`authHeroTitle`)：字号 `Display MD` (32px)，字重 `600`，允许通过换行符 `\n` 进行优雅分行。
   - 品牌说明文案 (`authHeroDescription`)：字号 `Body Large` (16px)，透明度 `rgba(255,255,255,0.85)`。
   - 品牌标识 (`brandSlug`)：统一转换为大写字符间距加宽展示（`tracking-widest`）。
3. **渐变暗层 (Overlay Scrim)**：
   - 在视频之上覆盖两层渐变遮罩：顶部 `linear-gradient(to bottom, rgba(0,0,0,0.6) 0%, transparent 40%)` 确保顶栏图标可读；底部 `linear-gradient(to top, rgba(0,0,0,0.8) 0%, transparent 60%)` 确保文字清晰度达 WCAG AAA。

### 1.2 右侧表单卡片规范
1. **表单容器**：
   - 最大宽度限制为 `420px`，居中对齐。
   - 内边距：桌面端 `40px`，移动端 `24px`。
2. **控件高度与圆角**：
   - 输入框高度统一为 `40px`，圆角为 `var(--r-md)` (8px)。
   - 主操作按钮高度统一为 `44px`，字号 `14px`，字重 `500`。
3. **第三方登录扩展 (Social Auth)**：
   - 支持 Linux.do OAuth 等第三方登录。按后台插件配置展示，按钮使用中性弱描边，图标靠左对齐，文字居中。

## 2. 暗黑极简登录页规范 (`/zh/login`)

针对特定创作者群体提供的暗黑沉浸式认证页面 (`DarkLoginPage`)：
1. **纯深色背景**：使用 `#09090b`（极黑灰色），避免刺眼反差。
2. **卡片微光边框**：表单外壳采用 `1px solid rgba(255,255,255,0.1)` 结合微弱内发光。
3. **输入框沉浸态**：背景色为 `rgba(255,255,255,0.04)`，悬停态为 `rgba(255,255,255,0.07)`，获得焦点时光圈为 `rgba(255,255,255,0.2)`。

## 3. 画布公开分享页规范 (`/share/canvas/:token`)

用于通过公开或加密链接分享的无限画布预览页面：
1. **只读保护**：画布完全处于只读（Readonly）模式，禁止节点拖动编辑、文字修改或删除。
2. **顶栏品牌条**：
   - 高度为 `48px`，背景为 `var(--workspace-surface)` 半透明毛玻璃。
   - 左侧展示当前站点 Logo 与画布名称。
   - 右侧提供“打开我的工作台”或“克隆画布”主要操作按钮。
3. **密码保护浮层**：加密画布访问时，居中弹出轻量密码验证卡片，验证通过前不加载节点真实内容。

## 4. 页尾与工信部备案规范 (Footer & ICP)

1. **版权声明**：
   - 格式：`© {当前年份} {brandName}. All rights reserved.`
   - 字号：`12px` (Caption)，颜色为 `var(--muted-foreground)`。
2. **工信部 ICP 备案号展示**：
   - 当后台 `icpFilingEnabled === true` 且 `icpFilingNumber` 不为空时强制展示。
   - 链接地址固定为工信部官方查询入口：`https://beian.miit.gov.cn/`，打开方式为 `target="_blank" rel="noopener noreferrer"`。
   - 禁止在未开启状态下伪造备案展示。

---

## 5. 移动端与响应式降级策略

1. **视口 < 1024px**：
   - 隐藏左侧品牌视频区，全屏聚焦于右侧表单操作区。
   - 在表单卡片上方自动引入小型品牌 Logo 与品牌名称，保持品牌可识别性。
2. **触控优化**：
   - 所有输入框与按钮保持 `≥ 44px` 高度，避免移动端软键盘弹出时布局挤压错乱。
   - 底部版权与备案信息保持单行折行自适应。
