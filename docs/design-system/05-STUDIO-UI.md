# 05 — AI 生成岛与创作工作台专属规范 (AI Studio UI Specification)

> **设计层级**：Layer 3 — Application Design System (Studio Scope)  
> **适用路由**：`/`、`/create`（首页创作岛）、`/toolbox/image`（图像工坊）、`/toolbox/video`（视频工坊）。  
> **核心定位**：AI 生成岛是 SupDance 面向创作者的核心业务阵地。必须提供流畅、沉浸、响应迅捷且数据真实的创作体验，严禁将枯燥的传统后台表单生搬硬套到工作台中。

---

## 1. 生成岛基础解构与布局体系

生成岛标准工作区（`CreationWorkspace`）采用“参数输入控制流 + 历史影像流”的协同布局：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        CreationWorkspace                               │
│  ┌───────────────────────────────────┬──────────────────────────────┐  │
│  │ 创作控制区 (Creation Dock)         │ 生成成果画廊 (Gallery Stream)│  │
│  │                                   │                              │  │
│  │ · 创作类型切换 (文生图/视频/音乐/对话) │ · 动态响应式瀑布流 / 卡片网格 │  │
│  │ · 模型选择器 (含提供商 Logo 与定价) │ · 真实任务进度卡片           │  │
│  │ · 提示词输入框 + 灵感优化器       │ · 成果预览大图 / 播放器      │  │
│  │ · 参考图/首尾帧拖拽投放区          │ · 批量操作 (下载/转入画布/扩增)│  │
│  │ · 参数矩阵 (比例/分辨率/风格)      │ · 异常重试与扣费明细         │  │
│  │ · 生成按钮 (含积分预估与防重提交) │                              │  │
│  └───────────────────────────────────┴──────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. 四大核心创作类型设计规范

### 2.1 文生图 / 图生图 (Image Studio)
1. **比例选择器 (Aspect Ratio)**：
   - 提供可视化比例图标按钮组：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`21:9`。
   - 按钮显示外框图形与比例数字，当前选中项高亮并赋予 `aria-pressed="true"`。
2. **参考图上传卡 (Image Reference)**：
   - 虚线拖拽边框，未上传时展示上传图标与“拖入参考图或点击浏览”。
   - 已上传时展示高精缩略图、权重滑块（Weight: 0.1–1.0）及一键清除按钮。
3. **风格与采样器预设**：
   - 提供视觉胶囊选择器（如写实摄影、动漫二次元、赛博朋克、古风水墨）。

### 2.2 生视频工坊 (Video Studio)
1. **关键帧控制 (First & Last Frame)**：
   - 分别提供“首帧”与“尾帧”两个吸附上传槽。
   - 支持从历史生成图或画布资产中一键带入。
2. **时长与运镜参数**：
   - 时长分段选择器：`4s` / `5s` / `10s`，禁止随意输入非法浮点时长。
   - 运镜模式（镜头推进、环绕、平移、变焦）配备直观微动效指示图标。
3. **视频成果播放器**：
   - 成果卡片内置轻量视频播放器，悬停时自动静音预览前 3 秒，单击展开高清全屏播放器。

### 2.3 生音乐 / 音频工坊 (Audio & Music Studio)
1. **歌词与提示词输入**：支持结构化歌词标签（`[Verse]`、`[Chorus]`、`[Bridge]`、`[Outro]`）高亮识别。
2. **曲风与 BPM 控制器**：支持按流行、电子、摇滚、古风等标签筛选。
3. **音频波形展示**：生成完成后渲染可交互式音频波形轨道（Waveform），支持播放游标拖拽与多轨分段下载。

### 2.4 文本模型与 AI 助手对话 (Chat & Agent Studio)
1. **流式打字机效果**：通过 SSE 消费文本块，采用 CSS GPU 加速实现平滑追加，禁止大幅页面跳动。
2. **Markdown 与代码高亮**：统一渲染 Markdown 标题、列表、公式与引用；代码块提供一键复制代码与语言标牌。
3. **思考过程折叠器 (Thinking Stream)**：DeepSeek / OpenAI o1 类模型的思考过程必须收敛于可折叠的卡片内，默认半透明，生成完毕后自动保持折叠态。

## 3. 生成状态机与“拒绝虚假进度条”纪律 (Status Machine)

### 3.1 严格状态机流转
所有任务状态必须严格由服务端返回的真实状态驱动：

```text
idle (闲置就绪)
  ↓ 用户点击提交
validating (客户端参数校验与余额预估)
  ↓ 提交成功
queued (已进入队列，展示队列排名位次)
  ↓ Worker 开始调度
processing (真实生成处理中，消费服务端轮询/推送事件)
  ↓ 终态流转
succeeded (生成成功)  /  failed (生成失败，展示真实错误原因)  /  cancelled (已取消)
```

### 3.2 严禁假进度条纪律
1. **禁止假动画**：绝对禁止使用前端 `setInterval` 凭空自增百分比的假进度条。
2. **如实表达进度**：
   - 若上游模型提供精确步数进度（如 `step: 18/25`），如实呈现步数与进度条。
   - 若上游仅提供处理状态，展示带有呼吸光效的“正在生成中...”与已耗时计时器，严禁虚报 `99%` 导致长时间卡顿。
3. **积分扣除与回滚透明**：
   - 任务创建时展示“预估消耗 X 积分”。
   - 任务失败时即时提示“生成失败，积分已自动原路返还”，并提供一键重试按钮。

## 4. 成果卡片设计规范 (Result Card System)

1. **媒体比例保持**：卡片外框必须严格匹配图片或视频的实际比例，加载期间使用骨架占位屏，防止排版抖动 (CLS 归零)。
2. **悬浮操作工具栏 (Hover Toolbar)**：
   - 鼠标悬停在卡片上时，在右上角浮现操作组：高清放大 (`ZoomIn`)、加入画布 (`Workflow`)、再创作 (`Sparkles`)、下载 (`Download`)、删除 (`Trash2`)。
   - 按钮采用不透明黑色微弱毛玻璃底色，对比度达标。
3. **信息徽章**：卡片底部常驻展示模型 Logo/简称、耗时（如 `4.2s`）与创建时间。
