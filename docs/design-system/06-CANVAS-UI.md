# 06 — 无限画布设计系统规范 (Infinite Canvas Design System)

> **设计层级**：Layer 3 — Application Design System (Canvas Scope)  
> **适用路由**：`/canvas`、`/canvas/:id`（项目画布）。  
> **核心定位**：无限画布是影视与短剧编排的“大脑与总控台”。具备高频缩放、大量多媒体节点并行、连线拓扑流转等特性，视觉规范与事件冒泡必须具备最高等级的空间隔离。

---

## 1. 画布空间与坐标隔离体系 (Spatial Isolation)

```text
┌────────────────────────────────────────────────────────┐
│  .canvas-workspace (全屏画布工作区，禁用全局外壳留白)  │
│  ┌──────────────────────────────────────────────────┐  │
│  │ .canvas-viewport (transform: translate + scale)  │  │
│  │                                                  │  │
│  │  · 网格背景 (--workspace-grid-line)              │  │
│  │  · 拓扑连线层 (SVG Edges & Connectors)           │  │
│  │  · 画布节点阵列 (.canvas-node)                   │  │
│  │    - 剧本/文本节点 · 角色与分镜资产节点          │  │
│  │    - 图片/视频生成节点 · 音频与台词节点          │  │
│  │                                                  │  │
│  └──────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 悬浮 UI 覆盖层 (Portal & Overlay: 屏幕固定坐标)   │  │
│  │                                                  │  │
│  │  · 顶部项目控制栏 (Project Topbar)               │  │
│  │  · 悬浮操作工具栏 (Canvas Toolbar)               │  │
│  │  · 画布小地图 (Canvas Minimap)                   │  │
│  │  · 视口缩放控制器 (Zoom Controls)                │  │
│  │  · 节点快捷命令条 (Node Toolbar)                 │  │
│  └──────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

### 1.1 绝对空间与屏幕坐标隔离
1. **世界坐标 vs 屏幕坐标**：
   - 画布内部的所有节点（Nodes）和连线（Edges）其位置、尺寸和变换只在世界坐标系内生效。
   - 工具栏、小地图、设置面板、右键菜单属于屏幕固定坐标，**绝不放入受 `transform` 缩放影响的 Viewport 内部**，防止文字模糊或缩放失效。
2. **滚轮与缩放边界守卫**：
   - 浮层容器（弹窗、下拉、抽屉、输入区）必须标记 `data-canvas-no-zoom` 或 `data-canvas-wheel-scroll`。
   - 画布引擎必须在捕获到带这些属性的目标时立即阻断画布视口缩放与平移，保证浮层内可正常滚动。

## 2. 节点系统规范 (Canvas Node System)

### 2.1 节点尺寸、圆角与表面
- **节点外壳圆角**：统一为 `var(--r-lg)` (12px)。
- **节点底色**：`var(--card)`，配合 1px 细边框 `var(--border)`。
- **节点阴影**：
  - 默认态：`var(--shadow-sm)`。
  - 悬停态：`var(--shadow-md)`。
  - 拖拽与激活态：`var(--elevation-overlay)`，并自动提亮发光层。

### 2.2 节点类型与语义色带 (Node Semantic Ribbon)
节点顶部包含 3px 语义色带或类型图标徽章，按业务类型严格对应系统调色板：
- **图片节点 (Image)**：`--palette-node-image` (琥珀黄)
- **视频节点 (Video)**：`--palette-node-video` (品红紫)
- **文本/剧本节点 (Script)**：`--palette-node-script` (紫色)
- **音频/台词节点 (Audio)**：`--palette-node-audio` (青蓝色)
- **分镜帧/机位节点 (Frame)**：`--palette-node-frame` (翠绿色)
- **角色/演员资产节点 (Character)**：`--palette-node-character` (桃红色)

### 2.3 节点交互状态矩阵
1. **未激活 (Default)**：边框为 `var(--border)`，Z-Index 为 `--z-node` (10)。
2. **悬停 (Hover)**：边框加深至 `var(--control-border)`，右上角浮现铅笔编辑入口。
3. **单选激活 (Selected)**：
   - 边框外侧包裹 2px 品牌主色光圈：`box-shadow: 0 0 0 2px var(--primary)`。
   - Z-Index 提升至 `--z-node-active` (20)。
4. **多选态 (Multi-selected)**：
   - 所有选中节点外围绘制统一的虚线选框，支持成组批量位移与删除。
5. **名称编辑契约**：
   - 节点标题必须包含显式可见的**铅笔编辑图标**，支持单击直接切入编辑输入态；**严禁将“双击”作为唯一编辑触发途径**（避免触屏与手绘板用户无法操作）。

## 3. 拓扑连线与连接桩规范 (Edges & Ports)

1. **连接桩 (Ports)**：
   - 位于节点左侧（输入 Input）与右侧（输出 Output）。
   - 外观：直径 `10px` 的正圆形，外加 2px 白色保护描边。
   - 交互响应：鼠标靠近时自动吸附扩大至 `14px`，并亮起对应类型色。
2. **连接线 (Edges)**：
   - 采用平滑三次贝塞尔曲线（Cubic Bezier）。
   - 默认线宽 `2px`，线色为 `var(--workspace-border-strong)`。
   - 选中线宽加粗至 `3px`，线色高亮为 `var(--primary)`，并在线段中心浮现快速删除按钮。

---

## 4. 悬浮工具栏与视口控制器规范

1. **浮动主工具栏 (Canvas Toolbar)**：
   - 居中吸附在视口顶部或底部，圆角为 `var(--r-full)` 胶囊形。
   - 工具选项（选择指针、抓手拖拽、文本工具、镜头工具、生成工具、橡皮擦）统一使用 `ToolButton`。
   - 当前选中工具拥有 `aria-pressed="true"`，并带有明确快捷键 Tooltip（如 `V`、`H`、`T`）。
2. **视口缩放与小地图 (Minimap & Zoom)**：
   - 位于画布右下角，包含缩放百分比显示（如 `100%`）、放大 (`+`)、缩小 (`-`) 与重置自适应视口 (`Maximize2`)。
   - 小地图展示当前视口红色矩形框与节点微型色块分布，支持单击直接平移定位。
