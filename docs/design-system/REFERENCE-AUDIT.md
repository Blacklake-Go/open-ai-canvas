## 1. 审计概述与证据体系

本报告对影策官方体验站（`https://yingce.tv/`）的视觉层次、交互状态机、设计变量、组件规范及响应式断点进行全流程、高精度实测与截图审计。

### 1.1 结论分级与标注规则

为确保所有技术决策与度量客观可溯，本报告内所有结论与参数严格打标分类：
- **[实测值]**：通过 Chrome DevTools Protocol (CDP) / DOM `window.getComputedStyle()` 提取的精准像素、色值、时间或结构。
- **[观察结论]**：基于高保真视口截图或连续状态机录制所推导的视觉与排版规律。
- **[估算值]**：因网络波动、动画过渡中间态或无法直接捕获的物理量所做的近似估计，均附带公差范围。
- **[项目建议]**：结合当前项目（`ddcat-ai/open-ai-canvas`）架构现状提出的标准化落地规范与演进决策。

## 4. 关键设计要素实测与结论

### 4.1 全局框架 (App Shell & Navigation)

- **顶部常驻通知条 (Notification Banner)**：
  - **[实测值]** 高度：`24px`，内边距：`0 32px`，字号：`13px`，字重：`400`。
  - **[实测值]** 关闭按钮：`24×24px` 正圆 (`border-radius: 9999px`)，右侧绝对定位 `right: 12px`。
  - **[观察结论]** 采用活动色强调（蓝紫/品红），文本居中对齐，支持单行截断与外链跳转。
- **侧边栏 (Sidebar)**：
  - **[实测值]** 展开宽度：`220px`；折叠后宽度：`64px`。
  - **[实测值]** 品牌标题高度：`56px`，带收起折叠按钮（`28×28px`，圆角 `8px`）。
  - **[实测值]** 导航菜单项：高度 `36px`，左右内边距 `12px`，圆角 `8px`，图标尺寸 `18×18px`，间距 `8px`。
  - **[实测值]** 分组标题（“资源与工具”）：高度 `26px`，字号 `11px`，字重 `600`，支持点击折叠分组。
- **顶栏 (Topbar)**：
  - **[实测值]** 高度：`48px`，背景为工作区底色透叠或毛玻璃。
  - **[实测值]** 交互药丸（语言、积分）：高度 `34px`，圆角 `8px`，背景色 `rgba(255, 255, 255, 0.043)` (暗色) / `rgba(15, 23, 42, 0.043)` (亮色)，字号 `13px`。

### 4.2 创作区域 (Studio Creator)

- **模式切换器 (Segmented Tabs)**：
  - **[实测值]** 高度：`48px`，选项包括视频、图片、文本、Agent。
  - **[实测值]** 激活选项卡：高度 `40px`，圆角 `12px` 顶部突起过渡，背景与下方输入框完全融合。
- **提示词多行编辑框 (Prompt Box)**：
  - **[实测值]** 占位符：“输入你的镜头、画面或故事。也可以添加参考图开始创作”。
  - **[实测值]** 容器背景：浅色下 `#ffffff`，深色下 `#18181b`；外边框：`1px solid rgba(0,0,0,0.06)` / `rgba(255,255,255,0.08)`；圆角：`16px`。
  - **[实测值]** 底部控制条高度：`42px`。
- **模型选择器 (Model Picker Trigger)**：
  - **[实测值]** 触发按钮高度：`34px`，圆角 `8px`，背景 `rgba(15, 23, 42, 0.043)`，内边距 `0 12px 0 10px`，字号 `12px`，右侧带 Chevron 图标。
  - **[实测值]** 弹出浮层：定位在输入框正下方，宽度与触发器贴合或默认 `320px`，圆角 `12px`，带 `elevation-overlay` 大阴影。
- **参数控制胶囊 (Parameter Pill)**：
  - **[实测值]** 高度：`34px`，圆角 `8px`，背景 `rgba(24, 24, 27, 0.05)`，文案 “1:1 · 自动 · 1”。
- **主操作按钮 (Primary Action Button)**：
  - **[实测值]** 高度：`34px`，圆角 `8px`，字号 `13px`，字重 `500`。
  - **[实测值]** 禁用态：背景灰色无描边；激活态：经典黑/白实底，带微抬升阴影。

### 4.3 浮层与弹窗 (Overlays & Dialogs)

- **认证弹窗 (Auth Dialog)**：
  - **[实测值]** 视口尺寸：宽度 `1000px`，最大宽度 `1408px`，两栏等高（约 `540px`）。
  - **[实测值]** 遮罩层 (Backdrop Mask)：`background: rgba(0, 0, 0, 0.45)`，`backdrop-filter: blur(5px)`。
  - **[实测值]** 左侧 Hero 栏：包含品牌 Logo、H1 大标题（`28px`，行高 `1.25`）、副标题、4 个特性卡片（`border-radius: 12px`，内边距 `12px 14px`）。
  - **[实测值]** 右侧表单栏：输入框高度 `42px`，圆角 `12px`，边框 `1px transparent`，背景 `color(srgb ... / 0.06)`；登录按钮高度 `42px`，圆角 `8px`，全宽。

## 5. 访问受限与边界记录

1. **鉴权拦截边界**：
   - 体验站未开放开放注册后的免审直接访问，非登录状态下点击私有业务（`/projects`、`/tasks`、`/assets`、`/canvas`）均会被路由守卫重定向并弹出登录模态框。
   - **[项目建议]**：在当前项目中保留清晰的未鉴权状态处理机，游客可访问公共展示页（`/create` 游客模式、`/login`、`/public`、`/terms`），强校验写路径与私有资产必须经过身份验证。
2. **模型运行时边界**：
   - 体验站未对未认证用户开放实时模型生成（触发器显示“当前没有可用模型”）。
   - **[项目建议]**：设计系统应提供完整的空模型、配置缺失、余额不足、排队中、生成失败的状态反馈组件，避免因后端未连接或模型下线导致页面空白崩溃。

## 6. 与当前工程代码的溯源与对比

经深度比对，参考站点 `https://yingce.tv/` 实际运行的是本项目（`ddcat-ai/open-ai-canvas`）的官方发行版本，其核心架构、CSS 变量名、组件类名（如 `.app-workspace-*`、`.auth-dialog`、`.yingce-classic-light`）与本仓库完全同源。

然而，生产站点的设计变量与前端代码存在部分散落的 Tailwind 内联类与第三方 Ant Design 默认样式的偶发覆盖。本次设计系统的核心任务，是将这些已验证的优秀设计沉淀为**三层解耦的 Design Tokens、强契约组件库与防覆盖插件机制**，使后续二开与业务升级不再随时间漂移。
