# 10 — 全站响应式与跨端布局规范 (Responsive Design System)

> **设计层级**：Layer 1 — Global Layout Foundations  
> **适用范围**：全站所有页面（桌面宽屏、常规笔记本、平板、移动端触屏）。  
> **核心原则**：禁止各个页面自造断点像素。所有响应式适配必须统一基于标准断点阶梯，兼顾键鼠操作精度与触屏点按易用性。

---

## 1. 统一断点阶梯体系 (Breakpoint Tokens)

全站严格采用以下 6 档响应式断点：

| 断点名称 | 媒体查询区间 | 典型设备定位 | 核心布局特征 |
| :--- | :--- | :--- | :--- |
| **XS (移动竖屏)** | `< 640px` | 智能手机竖屏 (iPhone / Android) | 单列纵向流、底部操作条、折叠抽屉菜单、触控优先 |
| **SM (移动横屏)** | `640px` – `767px` | 大屏手机横屏、小型平板 | 表单双列网格、弹窗居中卡片 |
| **MD (平板竖屏)** | `768px` – `1023px`| iPad 竖屏、平板电脑 | 侧栏默认收拢为图标栏、内容紧凑双列 |
| **LG (常规桌面)** | `1024px` – `1279px`| 笔记本电脑 (13/14 寸) | 侧栏展开常驻、两分栏工作台、表格列显示完整 |
| **XL (标准宽屏)** | `1280px` – `1599px`| 桌面显示器 (1080P) | 双列舒适布局、概览趋势并排、生成画廊 4 列 |
| **2XL+ (超宽屏)** | `≥ 1600px` | 2K / 4K 专业显示器 | 管理后台激活“主配置流 + 右侧固定摘要”双列极速操作 |

---

## 2. 关键区域响应式自适应策略

### 2.1 创作者工作台外壳与侧边栏
1. **桌面端 (≥ 1024px)**：
   - 侧边栏展开宽度为 `260px`（用户工作台）/ `224px`（管理后台）。
   - 提供垂直中部的平滑收折把手，支持一键折叠为紧凑图标栏或 0 宽。
2. **移动端与平板 (< 1024px)**：
   - 侧边栏完全移出常规文档流，转为左侧滑出式遮罩抽屉 (`AppDrawer`)。
   - 顶栏左侧展示汉堡菜单按钮 (`Menu`)，点击展开完整导航。

### 2.2 管理后台数据表格与设置流
1. **数据表格小屏策略**：
   - 表格严格禁止因为某列内容过长撑破整页；在小屏下必须**在表格容器内部横向平滑滚动**，固定首列（选择框/名称）与末尾操作列。
   - 绝不粗暴将多列数据表格降级为丢失横向对比效率的卡片列表。
2. **设置工作台大屏双列机制**：
   - 当屏幕视口达到 `1600px` 时，自动激活右侧 `344px` 固定状态指标卡。
   - 视口低于 `1600px` 时，状态指标卡自动平滑回到页面顶部，单列呈现设置流。

### 2.3 生成岛创作工作台响应式
1. **桌面端**：左侧固定创作控制 Dock，右侧自适应成果流。
2. **移动端**：
   - 控制 Dock 与成果流转为上下层叠结构，或通过顶部 Tab 进行“控制输入”与“生成成果”无缝切换。

---

## 3. 移动端与触控专项体验原则

1. **触控目标最小尺寸 (Touch Target Size)**：
   - 移动端所有高频交互按钮、图标点击区域、切换器必须保持 **≥ 44×44px**（可通过扩展伪元素 `::after` 扩大隐式触控区域）。
2. **软键盘与视口遮挡防护**：
   - HTML 页面 meta 视口标签声明 `interactive-widget=resizes-content`，保证软键盘弹出时视口高度正确重算，防止底部主操作按钮被键盘死死遮挡。
   - 表单提交按钮置于随软键盘抬升的安全区域内。
